## ISIT207-Front-End-Web-Programming-Tutorials

This repository is created to upload front-end web programming tutorial code, exercises, and examples for backup and to allow students to reference the code.
Each branch corresponds to a specific tutorial or week, making it easy to access the examples you need.

### 📁 How to Access Tutorial Code
- Navigate to the repository.
- Click on the **branch dropdown menu** (top-left).
- Select the branch for the tutorial or topic you want to view:
  - Tutorial-1 → Code examples for Tutorial 1
  - Tutorial-2 → Code examples for Tutorial 2
  - Tutorial-3 → Code examples for Tutorial 3 _(and so on for each tutorial)_

### 📁 Opening and Running the Files
- It is recommended to use **Visual Studio Code (VS Code)** along with the **Live Server** extension to open and run the HTML/CSS/JavaScript files.
- Simply clone the repository, switch to the desired tutorial branch, and open the project folder in VS Code.

### 🛠️ Steps

#### 1. Download/Clone the Repository
- **Option A:** Click the green **Code** button → **Download ZIP** → Extract the files.
- **Option B:** Use Git:

```bash
git clone https://github.com/your-username/ISIT207-Web-Programming-Tutorials.git
```

#### 2. Open VS Code
- Launch **Visual Studio Code** on your computer.

#### 3. Open the Project
- Go to **File → Open Folder...**
- Browse to the folder where you extracted or cloned the repository.
- Select the project folder and click **Open**.

#### 4. Run the Code
- Right-click the `index.html` file or the relevant HTML page.
- Choose **Open with Live Server** or click **Go Live** at the bottom-right of the VS Code status bar to view the webpage in your browser.

### 🎯 Purpose
- Provide a safe backup of tutorial and exercise code.
- Help students reference and learn from practical front-end examples.
- Ensure easy access, editing, and execution using modern web development tools such as **VS Code** and **Live Server**.

Happy coding and learning! 🚀
